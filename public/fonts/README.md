# Departure Mono

Self-hosted because it is not on Google Fonts.

- Source: https://departuremono.com
- Designer: Helena Zhang
- Licence: SIL Open Font License 1.1

Only a Regular weight exists, so nothing in the interface asks this family for
bold — synthesised bold destroys a pixel font. Emphasis is carried by
letter-spacing, case and colour instead.

The upstream site does not serve `OFL.txt` at a stable path, so the licence
text is not vendored here. Drop `OFL.txt` into this directory from the official
download if you need the full text alongside the binaries.
